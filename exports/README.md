# YUTA external deliverables

This directory is the single local destination for files prepared for someone
outside the YUTA engineering workspace.

The authoritative rules are in
[`docs/operations/EXTERNAL_DELIVERABLES.md`](../docs/operations/EXTERNAL_DELIVERABLES.md).

Use:

```text
exports/external/<recipient-class>/<domain>/<deliverable>/<version>-<status>/
```

All generated contents below `exports/` are intentionally ignored by Git. Keep
only this `README.md` in the repository. This directory is not approved storage
for real employee, customer, legal, financial, identity, or signature data and
is not a secure transfer channel.
