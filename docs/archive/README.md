# YUTA Documentation Archive

Status: Historical

Visibility: Engineering

Owner: YUTA product and engineering

Last updated: 2026-08-27

## Purpose

This archive preserves historical process evidence and provenance. Archive
content is not current Product Knowledge, architecture authority, lifecycle
authority, operations/readiness authority, or OpenSpec authority.

Archived wording is retained to show how current sources were produced. It
must not be interpreted as a current decision, requirement, lifecycle value,
implementation claim, deployment claim, or production approval.

## Current entry points

Agents should normally start from:

- [`docs/README.md`](../README.md);
- [`docs/PRODUCT_KNOWLEDGE.md`](../PRODUCT_KNOWLEDGE.md);
- [`docs/MODULE_REGISTRY.md`](../MODULE_REGISTRY.md);
- [`docs/AUTHORITY_MODEL.md`](../AUTHORITY_MODEL.md); and
- the scoped Product Knowledge Homes routed from Product Knowledge.

## Reading rule

Open archive content only when:

- investigating historical decisions or process;
- tracing provenance;
- comparing old and current behavior; or
- auditing how a current source was produced.

If archive content conflicts with current approved sources, the current
authority wins according to
[`docs/AUTHORITY_MODEL.md`](../AUTHORITY_MODEL.md).

## Preservation rule

Do not rewrite archived documents merely to make them current. Their historical
wording is part of their provenance. Repair a link only when required to keep
the archived material readable, and never promote an archive path as a current
authority.
