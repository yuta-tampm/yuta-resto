## One-way proof and fail-closed risk review

The permitted chain is non-authoritative canonical `PRE_DECISION_DESCRIPTOR` → positively accepted Human Gate result → canonical `GATE_RESULT_RECEIPT` → immutable `APPROVAL_RECORD` → immutable semantic decision record → durable consumption. `DECISION_ID` is derived before the Human Gate from canonical type, scope and proposed payload. The approval record uses only evidence already available when it is written; it has no self-hash or later semantic-record hash. The semantic record is written only after approval-record persistence, hash computation and read-back, and binds that exact hash. No predecessor requires a later artifact hash.
