## Non-negotiable transaction and test contract

A viable future Design must name the actual executable and browser/session boundary. One process acquires the existing execution-context FileShare.None lock, reconciles state, validates and durably consumes the exact `LIVE_TOWER_SELECTION` chain, directly invokes the trusted browser mechanism while retaining that same lock, binds the observation to context, lineage, target run, instance, Project, exact conversation, title/URL, epoch and probe identity, then durably records result or delivery/execution uncertainty and snapshot convergence before releasing the lock. `ACTIVE_COMMIT` requires both independent Human authority and fresh real observation. Caller stdin may provide request parameters but never trusted observation provenance. No independent second helper invocation, timeout resend or replay repairs uncertainty.

Later focused tests must reject raw or copied observation JSON, forged source markers, fixture selection in production, wrong target/Project/run/instance/probe, replay, and Human-only or observation-only activation. They must show the same parent lock remains held during actual adapter invocation, a competing same-context process cannot acquire it, child failure produces durable uncertainty before release, and one valid exact read-only observation with valid consumed Human authority can reach the isolated synthetic executable-state path. Synthetic tests are never live Browser QA.

Only bounded identity, URL/title if required, timestamp, state, references and hashes may persist. No full page text, transcript, customer/private Page Chat content, credential, token, cookie or session. PAGE_LOCAL Product/shaping authority, Workflow v3 escalation, Bridge v1 wire grammar and the approved Spec requirement remain unchanged.
