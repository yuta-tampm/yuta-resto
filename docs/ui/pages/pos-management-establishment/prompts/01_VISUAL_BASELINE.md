decisions in `ACCEPTANCE_CHECKLIST.md`. Use the ready prompt in
`DESIGN_HANDOFF.md` to generate a design proposal; do not implement runtime
code automatically.

development-only discovery evidence. Reuse `ManagementHeader`; do not create a
working hub link, contract, API, database row, receipt field, or cloud relation.
